Vkit

Vision ID Kit

Identify residents’ eyeglasses. One kit labels up to 300 pairs of glasses.

How it works

The Vision Kit is designed to work with the LTS “C” size laundry labels.

  1. Write the name on the label.
  2. Slip it inside the plastic shrink tubing.
  3. Slide the assembly over the ear frame.
  4. Shrink with the thermal gun.

Less than one minute later, the eyeglasses are secure with the resident’s name.

What’s in the kit

  • Labels up to 300 eyeglasses
  • 50-foot roll of clear shrink tubing
  • Industrial LTS thermal gun
  • 3/8″ × 2″ white “C” size labels (300 labels)
  • Carrying case
